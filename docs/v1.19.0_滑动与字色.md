# v1.19.0 · 左右滑动切页 + 液态字色可读性

用户反馈两件事，都是真 bug，不是「用不惯」：

1. 「从主页向右边滑动，没办法进入到右边的闹钟」
2. 「曜石深潭、薄荷清露这两个界面，字真的看不清楚」

## 一、左右滑动：以前根本没实现

`RootShell` 的外壳一直是 `IndexedStack` + 自绘底栏，五个页面叠在一起，只有 `onTap` 切 `_index`。**没有 `PageView`、没有任何横向手势识别器**，所以左右划一百次也不会翻页——不是手势被谁吞了。

改成 `PageView` + `PageController`：

- `onPageChanged` 写回 `_index`，底栏高亮跟着手势走；
- 点底栏也走同一个 controller 的 `animateToPage`，不会「按钮切了页、controller 还停在旧页」；
- 页面内是 `ListView`（竖向滚），与 PageView 的横向手势分属不同方向，不抢手势；
- 没有 `Dismissible` / 横向拖拽控件，不存在手势冲突。

回归用例在 `test/app_smoke_test.dart`：慢速拖一页 → 1.0 → 拖回 → 0.0 → 点底栏跳到「我的」→ 4.0 → 再拖回一页 → 3.0。用 `timedDrag(600ms)` 而不是 `drag`，后者带惯性会一次翻两页（真机快速甩也会，属正常行为）。

## 二、字色：液态主题没有自己的字

根因在配色链路：

- 卡片底色：`AppColor.glassCard` 在 v1.17.1 已经改成取液态主题的 `surfaceOf` ✅
- 卡片上的**字色**：`AppColor.ink` / `sub` / `accent` 仍然只取纸感主题 ❌

于是曜石深潭的卡片是暗绿 `0xFF465F58`，字却是「暖纸」的近黑 `0xFF1C1A17`——暗字压暗卡，户外基本糊成一片。薄荷清露是亮卡，但次文字是灰褐 `0xFF8C857A`，也偏淡。用户切到「墨夜」时则相反，浅字压亮卡，同样难受。

### 改法

给 `LiquidTheme` 加 `ink` / `sub` / `accent` 三个字段，四套风格各自带一套字色；`AppColor` 在 `Liquid.on` 时从液态主题取字色，关掉液态则原样退回纸感主题——**原来的六套配色、三套质感一个像素都没动**。

| 风格 | 卡片 | 主字 | 次字 | 强调 |
|---|---|---|---|---|
| 香槟晨曦 | 暖白亮卡 | `0xFF2F2519` | `0xFF6A5947` | `0xFFB0703D` |
| 极光棱镜 | 冷紫亮卡 | `0xFF1D1A2E` | `0xFF5A5672` | `0xFF7C67C9` |
| 曜石深潭 | 暗绿卡（提亮一档） | `0xFFF2FAF6` 浅字 | `0xFFB8D8C9` | `0xFF6FE0B8` |
| 薄荷清露 | 薄荷亮卡（拉开层次） | `0xFF12312C` 深墨绿 | `0xFF3E6B5E` | `0xFF3E9073` |

配套：

- 曜石深潭卡片 `0xFF465F58→0xFF4F6D62`、描边同步提亮，浅字才立得住；
- 薄荷清露卡片上下端从 `#E6F8F0→#BEE0D2` 拉成 `#F3FBF7→#C7E7D8`，层次更明显；
- 闹钟/我的里三处写死的褐色说明字改走 `AppColor.softInk`：旧风格保持原褐色，液态下换成该主题次文字；
- `onInk` 与状态栏图标改按**实际字色明暗**（`AppColor.textIsLight`）选正反色，不再只看纸感主题的 `isDark`。

### 对比度有测试看住

`test/liquid_test.dart` 用 WCAG 相对亮度算四套风格的字/卡对比度：主字 ≥ 4.5:1、次字 ≥ 3:1，并要求「暗卡配浅字、亮卡配深字」。以后谁改配色把字压回背景上，测试直接红。

## 验证

- `flutter analyze`：0 error（剩 2 个既有 unused_import）
- `flutter test`：248 项全过
- 真机（平板 24018RPACC，Android 16，横屏 3048×2032，装 1.19.0+35）：
  - 首页手指左滑 → 进入闹钟页，底栏「闹钟」同步高亮；往返滑动正常
  - 曜石深潭：选项标题与说明小字变成浅色，深绿卡上清晰可读，不再是照片里那种糊成一片
  - 薄荷清露：卡片字为深墨绿、背景字为浅青白，层次分明；顶部说明和「偏好 / 外观」分组标题也一并变亮（这些字直接画在背景上，不能跟卡片字用同一套颜色）
  - 进程存活，`logcat -b crash` 无本包记录
