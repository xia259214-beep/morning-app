## 分享卡

`python tools/share_card.py` 会生成一张 1080×1680 的图（默认落在
`build/share/晨序MORNING_分享卡.png`），带两个二维码：① 下载页 ② 当前版本直链。
版本号和体积从 `pubspec.yaml` 与构建产物里读，发版后重跑一次即可。

生成后建议实际扫一遍再发出去——二维码这类东西不能靠肉眼判断。

## 三个要提醒对方的点

1. **允许安装未知来源**：小米/华为/OPPO 会弹风险提示，选「仍要安装」。
2. **换手机要自己搬数据**：「我的 → 数据备份 → 导出到文件」得到一个 JSON，
   新机「从文件导入 → 合并」即可。打卡照片不随备份走（设计如此）。
3. **老版本不会自己提示更新**：1.16.0 之前没有「检查更新」这套代码。
   如果对方装的是更早的版本，得手动装一次 1.18.0 以后的版本，之后才会有更新提示。

## 国内网络的现实问题

- GitHub 在国内经常连不上或很慢，`releases` 页尤其明显。
- App 里的「检查更新」请求的是 `api.github.com`，被墙时会**静默失败**
  （不弹错误，就是不提示有新版）。这是有意为之：早上七点没人想看网络异常。
- 所以给国内朋友分享时，**最稳的是直接发 APK 文件**（微信/QQ 传文件），
  或者自己传一份到网盘再把链接发出去；GitHub 链接当备选。
- 真要让所有人都能稳定收到更新，得加国内镜像或自建更新源——这属于要动
  架构的事，等确定分发规模再说。
