# v1.21.0 · 榜单去掉「内置」标签 + 每行分科明细 + 十维 A–F 评级

## 用户要的是什么

> 「答题榜的那个真人，或者是内置的，把那内置两个字给去掉，还有后面那个分数，
> 是什么科目加多少分？体育还是文化还是科技，要在每一个后面写清楚总分是多少分，
> 不能光一个总分。一定要把那个内置那两个字给去掉。
> 还有我的段位，它旁边不是有个圈吗？什么科技、生活、军事、环境什么的，
> 要有一个欧美的评分系统，那个评分就叫 A B C D E F。」

三件事，逐条落地：

1. 榜上不再出现「内置」两个字；
2. 每一行说清「这几分是哪几科挣的」+ 总分；
3. 段位卡那个十边形，每个角加一个 A–F 等级，整体给一个「综合」等级。

## 一、去掉「内置」标签

原来每一行的昵称后面挂一个灰色小牌「内置」，榜下一行写「X 位真人 · Y 位内置对手」。
标签去掉，说明留在榜下：

- 概况行改成「X 位真人 · Y 位陪练角色」
- 说明改成「陪练角色是 App 自带的（分数跟着你的水平走，前面永远有人可追），
  不冒充真人」

标签去掉，话不说谎——这比「装作全是真人」和「每行都挂个假字」都更接近用户要的东西：
榜单看起来是一张正常的榜，同时任何人想知道这些分是怎么来的，往下看一眼就有答案。

代码：`lib/pages_rank.dart` 的 `_boardRow()` 删掉徽章、`_boardCard()` 换文案。

## 二、每行写清科目加减分

### 数据从哪来

原来只记一个总分（`ScoreBook.total = 答对 − 答错`），不知道分落在哪一科。
这一版在账本里多开一格 `byAxis`：

- 判分时把题目的领域（`q.axis`，十维之一）一起记进去，答对 +1、答错 −1；
- 跳过和偏好题不计分，所以也不落科目（跳过是「这块先不问」，不该记成这科失分）；
- 十项相加 = 总分。这条恒等式写进单测，榜上的数字才敢摆出来。

旧账没有分科。**不硬拆**——把 21 道旧题的总分按十份均摊，看着漂亮，其实是编的。
单独留一个「往期」项：`往期 = 总分 − 各科之和`，界面上标「往期」，
榜下一句解释「这一版之前的总分，当时没分科记账」。

### 云端

表格 `morning_scores` 加一列 `axes jsonb NOT NULL DEFAULT '{}'::jsonb`：

```sql
ALTER TABLE morning_scores ADD COLUMN IF NOT EXISTS axes jsonb NOT NULL DEFAULT '{}'::jsonb;
```

上报时一起写 `axes`，拉榜时一起读。老行是 `{}` → 界面只显示总分，不显示分科。

### 陪练角色的分科

陪练的分是「我的分 + 偏移」，没有真实过程，但榜上每一行都要能对上账，
所以按固定权重 5:3:2 摊到三科上（总分为负就摊成负的，余数补最后一科，
三科相加必须正好等于总分），科目按昵称做种子挑——刷新一次不会换一批科目。

### 显示

每行两排：`名次 · 昵称 ····· 总分 30`，第二排小字 `文化 +15 · 健康 +9 · 生活 +6`。
取绝对值最大的三科，多的收成「等 N 科」，保证行宽不炸、也不把整张榜变成表格。

自己那一行如果还没有任何得分，第二排写「答一题就有分科明细」，不留空行。

「我的 → 总分」弹层里也加了同一份明细（含往期说明），两处口径一致。

## 三、十维 A–F 评级

新文件 `lib/grade.dart`（类名 `AxisGrade`，避免和题库里判对错的 `Grade` 撞名）：

| 等级 | 战力 | 读法 |
| --- | --- | --- |
| A | ≥ 85 | 问得住 |
| B | ≥ 68 | 稳 |
| C | ≥ 50 | 还没看清 |
| D | ≥ 35 | 偏弱 |
| E | ≥ 20 | 弱 |
| F | < 20 | 基本空白 |

- 十维从 50 起（「还没看清」），所以新人打开是十个 C —— 不是一屏红叉。
- 中间档的边界都落在 50/68/85 上，单测把 84.9 / 67.9 / 49.9 这些边界值钉死了。
- **综合等级**取十维平均再换字母，不是取最弱那科：单科的弱项在雷达图上自己会塌下去，
  不必在这里再罚一次。综合等级做成紧跟段位名的小胶囊「初醒 · C 综合」。

雷达图（`lib/radar.dart`）新增 `grades` 参数：给了就画两行角标，科目名在上、
字母在下（accent 色加粗），留白从 30 加到 40 免得贴边。尺寸跟着卡片宽度走
（`0.46 × 宽度`，夹在 186~300），手机上不挤、折叠屏摊开不空。

雷达下方还有一行十个「科目 等级」，想数一遍的人不用去读图上那些小字。

## 顺手修掉的

段位页的页面级文字（标题「晨序榜」、小标题「段位阶梯」「跟朋友对拼」、说明段落）
原来用的是卡片字色，画在深色背景上几乎看不见。改成 `bgInk / bgSub / bgAccent`——
这是 v1.19.0 定下的两层字色规矩：卡片里用 `ink/sub`，画在背景上用 `bgInk/bgSub`。

## 还留着的坑

- **自己那行现在没有分科**：这台手机上的 21 道题是 v1.15.0 之前答的，当时还没有总分账本，
  所以总分 0、分科空。从这一版起，答一题就有一格。
- APK 还是 53 MB（分包瘦身没拍板）。
- 真人 0 位时陪练 8 位、有 1 位真人时陪练 1 位——名次会因此往前跳，
  这是「1:1」这条规则带来的，要不要改成「陪练固定 8 位」还没定。
