# 晨序 MORNING · 视觉设计系统 v1「液态水晶」

> 版本：v1.17.0 · 日期：2026-11-24
> 状态：第一版已落地（四套风格 + 太阳光晕 + 按钮/卡片组件）；封面为设计方案，待下一版实现。

---

## 一、设计原则

用户原话提炼：

1. 「按键要柔和、玻璃感、前后分层、按动要有水晶感、整体要有时尚感」
2. 「那道光不要扫过去，要像手指点上去散开来，像水一样荡开」
3. 「光晕跟着时间走，一天 24 小时转圈，太阳到哪方向哪边就亮一点」
4. 「原有风格不需要去除，可以再往里面添加，让每个人能选择的多一些」

由此定下三条铁律：

- **添加不替换**：原来的 6 套配色、3 套质感全部保留。液态水晶是并列的第四种质感，不选它就和旧版一模一样。
- **结构统一、配色可换**：四套新风格共用同一套组件结构（封面 / 板块 / 背景 / 按键），只换一组颜色参数。
- **光有时间语义**：背景光不再是随机飘的装饰，而是绑在真实时钟上的太阳轨迹。

|---|---|---|---|---|---|

| `obsidian` | 曜石深潭 | 深色高级，按键像点亮的水面 | `#0C1412` | `#3CCDA5` | `#CDF5E6 → #96D7C3` |

## 三、组件的四层结构

### 3.1 按键 `LiquidButton`

从底到顶四层：

1. **外投影**——`0 9px 20px`，让按键浮起来
2. **玻璃本体**——`topLeft → bottomRight` 斜向渐变，1.2px 描边
3. **内部光晕**——一颗缓慢漂移的柔光，让材质有厚度
4. **涌光**（按下时）——从**触点**扩散的径向光晕，0.52 秒淡出

按下态：`scale(0.975)` + 投影收紧 + 内阴影加深（苹果 CG 那种实体下压感）。松手回弹用 `Curves.easeOut`。

未选液态风格时，组件直接退回原来的 `FilledButton`，视觉零差异。

### 3.2 卡片 `LiquidFrame`

1. **外发光**——卡片自身洇出的柔光，让它浮在背景上（这是「前后分层」的来源）
2. **渐变玻璃**——斜向渐变 + 顶部高光 + 底部暗边
3. **棱镜描边**——三色线性渐变描边（水晶与塑料的分界线）
4. **顶部反光**——一条 1.4px 的白色细线

 featured 卡（主卡）描边 1.8px、外发光更强；次卡 1.2px、更收敛。

### 3.3 背景 `LiquidBackdrop`

一次 `CustomPaint` 画完，不启动动画：

- 底色铺满
- 主光斑：位置 = 太阳方位，亮度 = 太阳高度
- 补光斑：对称侧，夜里也在，保证背景不全黑

5 分钟刷新一次坐标（太阳一小时才走 15°，肉眼察觉不到跳变），几乎不耗电。

## 四、太阳光晕算法

```dart
h = hour + minute / 60
t = (h - 6) / 24 × 2π
x = 0.5 + 0.34 × cos(t)     // 屏幕横向比例
y = 0.5 − 0.34 × sin(t)     // 屏幕纵向比例
altitude = clamp(sin((h - 6) / 12 × π), 0, 1)
opacity = 0.10 + 0.34 × altitude
```

| 时间 | 方位 | 效果 |
|---|---|---|
| 06:00 | 正东（右） | 从右边亮起 |
| 12:00 | 正南（上） | 顶部最亮 |
| 18:00 | 正西（左） | 转到左边 |
| 00:00 | 正北（下） | 沉到底下、最暗 |

与旧背景的区别：旧的是 22 秒一圈的呼吸漂移（装饰性），新的是绑真实时钟的太阳轨迹（有时间语义）。两者互不干扰——选了液态风格才启用太阳背景。

## 五、设置入口

`我的 → 界面质感` 页面分三组：

1. **液态水晶 · 新**：「用回原来的风格」+ 四套新风格，各带缩略图
2. **原来的三套质感 · 都保留**：原纸 / 水晶 / 流光
3. **动效与声音**：波光流动开关、播报语速

选任意一项立即生效并持久化（`liquidId` / `glassId`）。选原来的质感会自动关掉液态风格，两套不会打架。

## 六、封面设计方案（下一版实现）

封面是这一版唯一还没落地的部件。三个方向：

### 方向 A · 日出刻度
- 深色底，中央一条**弧线**象征太阳轨迹
- 弧线上一个光点，位置 = 当前时刻的太阳方位
- 「晨序 MORNING」字压在弧线起点，时间数字最大、最轻（weight 200）
- 底部标语：`让每一个清晨都有意义`
- 亮点：封面本身就是一只「日晷」，第一天就建立产品性格

### 方向 B · 光从边缘来
- 背景是一整块液态玻璃，光晕按当前时间从对应方向洇入
- 品牌字用棱镜描边（跟按钮同一套描边语言）
- 亮点：跟液态水晶系统完全一家人，最省钱实现

### 方向 C · 极简白纸
- 保留旧封面，只在角落加一颗会随时辰变色的光点
- 亮点：最克制，老用户零适应成本

**推荐 A**——它把「太阳」这个核心意象直接做进第一眼，且和背景光晕是同一个数据源，逻辑自洽。

## 七、性能与兼容

- 背景光晕一次绘制、5 分钟刷新，不随页面滚动重绘
- 按钮涌光是短促的一次性动画（0.52s），不常驻
- 卡片模糊只在 featured 主卡上启用；列表类次卡用色块 + 描边，省 GPU
- 低端机兜底：若掉帧，把 `BackdropFilter` 降级为半透明色块，质感靠描边和高光撑住
- 所有组件在 `Liquid.on == false` 时走旧路径，旧主题用户零影响
