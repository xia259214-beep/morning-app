# v1.18.0 · 本机档案：头像与称呼

用户原话：
> 更新一个 APP 的头像还有登录界面，这个登录界面你之前是怎么做的，APP 的头像要能换本地和拍照的，不然的话我点进去想换个头像换不了。还有账号你是怎么做的，是手机号码、邮政邮箱，还是什么一键登录、游客登录？

先把事实说清楚，因为这决定了改法。

## 一、之前没有登录界面

这个 App 从 v1.0 到现在**没有任何账号系统**：

- 「我的」页那个「晨友」是 `pages_more.dart` 里写死的一行 `Text('晨友')`；
- 旁边的头像是一个写死的 `Icon(Icons.wb_twilight)`，套在圆圈里，没有点击响应——所以点进去当然换不了；
- 所有数据（闹钟、打卡、答题、战力和总分）都在本机 `SharedPreferences` 的 `alarms` / `records` / `settings` 三个键里；
- 「换手机」是靠 v1.15.0 的「数据备份 → 导出 JSON → 新机导入」，不是靠登录。

## 二、为什么不做真账号（手机号 / 邮箱 / 一键登录）

真账号不是界面问题，是**要有服务器**：手机号登录得有短信通道和云数据库，邮箱登录得有邮件服务和验证码存储。随之而来的是费用、隐私政策、实名要求，以及「断网或被墙就登不上」。

而这个 App 的立身之本是「数据全在本机，不上传服务器」。加账号等于把这个卖点换成一个大概率用不上的同步功能——闹钟和播报本来就跑在本机，账号唯一的意义是多设备同步，而那个需求已经被备份 JSON 解决了。

所以这一版做的是**本机档案**：一张头像、一个称呼。不注册、不联网、不用实名。

> 以后真要做多设备同步，也是先有「本机档案」，再在它外面套同步，而不是先有账号再想办法塞数据。

## 三、这一版做了什么

### 1. 头像能换了（拍 / 选 / 恢复默认）

点头像（圆圈右下角有个小相机角标）弹出三项：

| 选项 | 走什么 | 说明 |
| --- | --- | --- |
| 拍一张 | `MediaStore.ACTION_IMAGE_CAPTURE` + FileProvider | 拍完原图写在 `cache/avatar/`，处理完立刻删掉 |
| 从相册选 | `Intent.ACTION_OPEN_DOCUMENT`（`image/*`） | 系统选择器，**不需要存储权限**，网盘里的图也能选 |
| 恢复默认头像 | 删掉 settings 里的键 | 没设过头像时不显示这一项 |

两条来源都汇到同一个函数 `MainActivity.avatarFromUri()`：

1. 先 `inJustDecodeBounds = true` 读尺寸（不解码像素，不占内存）；
2. 按 2 的幂算 `inSampleSize`，**先采样再解码**——不这么做，一张 5000 万像素的照片会直接 OOM，不是慢，是进程被杀；
3. 居中裁正方形（不改宽高比，不变形）；
4. 缩到 256×256，JPEG 质量 88；
5. `Base64.NO_WRAP` 编码后交回 Dart。

头像是**存 base64 而不是存文件**：省了文件生命周期管理，而且它天然躺在 `settings` 里，备份 JSON 会带着它走，换手机头像不丢。256px/88 一般 15–30 KB，不会把备份撑大。

### 2. 称呼能改了

「晨友」不再是写死的。点名字（带铅笔图标）→ 输入框 → 保存，限 12 个字。

规则：去首尾空白、连续空白压成一个空格、超长截断；**删空了退回「晨友」**，不留一个没名字的档案。

### 3. 坏数据不会把页面搞崩

头像是一段可能被人手改过的字符串。`Avatar.decode()` 三道关：base64 能不能解、长度是否在 64 B–400 KB 之间、头两字节是不是 JPEG 的 `FFD8`。任何一关不过就返回 null，界面退回默认图标——**绝不因为一条坏数据让「我的」页白屏**。

## 四、真机验证（小米平板 24018RPACC · Android 16）

| 项 | 结果 |
| --- | --- |
| 点头像 | 弹层出现「换个头像 / 拍一张 / 从相册选」，无头像时确实不显示「恢复默认」 |
| 从相册选 | 系统选择器 → 选 1200×900 测试图 → 头像变成居中裁切的正方形，填满圆圈不变形 |
| 重启 | `force-stop` 后重新打开，头像还在 |
| 恢复默认 | 点一下回到默认图标，同时该项从弹层里消失 |
| 拍照 | 相机成功拉起（`com.android.camera`） |
| 取消拍照 | 返回键退出后回到 App，头像没变、没报错、进程存活、`logcat` 无本包异常 |
| 昵称 | 改成 `TestName` 生效并持久化；清空后保存退回「晨友」 |

**没验到的**：这台平板的相机界面不响应 `input tap`（取景全黑、合成点击不进），所以「拍照 → 确认 → 头像变成照片」这一条没跑完。它和「从相册选」共用 `avatarFromUri()`，差别只是文件来源，风险很低，但没有真机证据就是没有，如实记在这里。

## 七、留给以后

- **真账号 / 多设备同步**：要做就得先有后端（云数据库 + 短信或邮箱验证码），涉及费用与合规。目前的答案是「不做」。
- **多档案切换**（一台手机几套数据）：数据结构要按档案分桶，改动比这一版大，等真有需求再说。
- **头像进分享卡 / 闹钟页**：现在只用在「我的」页，别处仍是品牌图标。
