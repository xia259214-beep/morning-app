### 导出 / 导入真机端到端

之前只在单测里验过，这次在手机上真点了一遍：

1. **导出** → 系统文件选择器（`documentsui.PickActivity`）弹出，默认名
   `晨序备份_2026-11-23_2321.json`，存到「下载内容」。
   落盘 **104,417 字节**，`/sdcard/Download/晨序备份_2026-11-23_2321.json`。
2. **内容校验**：顶层 `app=morning`、`schema=1`、`version=1.16.2`、`exportedAt`、
   `prefs{alarms, records, settings, journal}`；闹钟 1 条、打卡记录 2 条、
   设置 46,914 字符、流水 10,897 字符，JSON 可正常解析。
3. **导入** → 小米文件选择器（`com.android.fileexplorer.picker`）→ 浏览 →
   内部存储 → Download → 选中该文件 → 确定。
4. **预览弹窗**内容与备份一致：`2026-11-23 23:21 导出 · v1.16.2`，1 只 / 2 天 / 84 条 / 38 道 / 0 分，
   合并与覆盖的说明文案都在。
5. **合并导入**结果：`闹钟 0 只 · 打卡 0 天 · 流水 0 条`——自己导出的文件再合并回来是
   空操作，判重正常，没有写出重复条目。总数复核仍为 1 / 2 / 84 / 38。
6. 页面出现「上一次导入前的数据还留着，点错了可以换回去」的撤销入口。

### 一个容易误会的地方：总分 0

手机上「已答 38 题」但「总分 0 / 答对 0 / 答错 0 / 正确率 0%」。

这不是数据丢失：1.15.0 之前的版本只把答过的题记成题目 id 集合（`Profile.answered`），
**没有记对错**，打卡记录里的 `quizCorrect` 也恒为 0。所以这 38 题算不出分，也不该猜。
分数从 1.15.0 起才逐题累加，老用户升级后总分从 0 开始是正确行为。
