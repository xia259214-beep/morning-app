## 2. 「可选择」怎么落到 APP 设置里

### 设置项结构

```
设置 → 外观 → 按钮材质
  ├─ 单选列表（7 项，来自 skins.json 的 skins[]）
  ├─ 每项显示：名称 / 族 / 一句说明 / 对比度 / 材质小预览
  ├─ 选中态：aria-pressed=true（Web）/ checked（原生）
  └─ 底部：「恢复默认」→ glass
```

### 状态与持久化

| 项 | 值 |
|---|---|
| 持久化 key | `morning.skin` |
| 默认值 | `glass` |
| 合法值 | `glass / frosted / system / well / ghost / row / contrast` |
| 非法值处理 | 静默回退 `glass`，不要崩、不要空白按钮 |
| 切换时机 | 立即生效，无需重启；只换 token，不重建视图 |
| 系统联动 | 系统开启「增加对比度 / 降低透明度」时，**建议自动切到 `contrast`**（对应 Apple HIG 的设置适配） |

### 切换时不要做的事

- 不要改按钮 DOM 结构、高度、圆角、文字、箭头
- 不要加发光 / 涟漪 / 外扩描边 / 实色侧壁 / 第二层阴影
- 不要用 `translateY` 表达按下（会让底缘与投影错位，出现「泛白」）
- 不要重新创建按钮实例（会丢焦点、打断读屏）

## 3. Token 映射表

| Token | 含义 | 原生对应 |
|---|---|---|
| `--cta-face` | 表面填充（渐变或纯色，允许 `transparent`） | `Brush` / `GradientDrawable` / `background` |
| `--cta-fg` | 文字与箭头颜色 | `contentColor` / `textColor` |
| `--cta-blur` | 背景模糊与饱和（`none` 表示不模糊） | `RenderEffect.blur` / `backdrop-filter` |
| `--cta-edge` | 1px `inset` 中性细描边 | 内描边 `stroke` |
| `--cta-top` | 1px 顶部方向性高光 | 内顶线 |
| `--cta-bottom` | 1px **底部暗线收口**（防泛白的关键） | 内底线 |
| `--cta-press` | 按下时 6px 内凹阴影 | `inset` shadow |
| `--cta-cast` | 外部接触阴影，近乎为零 | 外阴影（4 档设为透明） |

**骨架（只写一次，7 档共用）**

```css
.ph-cta{
  background:var(--cta-face); color:var(--cta-fg);
  backdrop-filter:var(--cta-blur);
  box-shadow:
    inset 0 0 0 1px var(--cta-edge),
    inset 0 1px 0 var(--cta-top),
    inset 0 -1px 0 var(--cta-bottom),
    var(--cta-cast);
  transform:scale(1);
}
.ph-cta.down{transform:scale(.972);
  box-shadow:inset 0 0 0 1px var(--cta-edge),
    inset 0 1px 0 rgba(255,255,255,.06),
    inset 0 -1px 0 var(--cta-bottom),
    inset 0 6px 14px var(--cta-press),
    0 1px 3px -2px rgba(0,0,0,.45);
  filter:brightness(.94)}
/* 回弹 320ms cubic-bezier(.22,1,.36,1)，峰值 1.006 */
```

## 4. 接入示例

### Web / WebView（最省事）

```html
<link rel="stylesheet" href="skin-tokens.css">
<div data-cta="glass"><button class="ph-cta">开始今日</button></div>
<script>
  var id = localStorage.getItem('morning.skin') || 'glass';
  document.querySelector('[data-cta]').dataset.cta = id;
</script>
```

切换只要一行：`container.dataset.cta = 'well'`。`index.html` 已完整实现这套逻辑，可直接当设置页用。

### Jetpack Compose

```kotlin
enum class ButtonSkin(
    val face: Brush, val fg: Color, val edge: Color,
    val top: Color, val bottom: Color, val press: Color,
    val blur: Float, val cast: Dp
) { /* 7 档，按 skins.json 填值 */ }

@Composable
fun MorningCta(skin: ButtonSkin, onClick: () -> Unit) {
    var pressed by remember { mutableStateOf(false) }
    val scale by animateFloatAsState(if (pressed) .972f else 1f,
        spring(dampingRatio = Spring.DampingRatioNoBouncy, stiffness = 420f))
    Box(
        modifier = Modifier
            .fillMaxWidth().height(48.dp)
            .scale(scale)
            .clip(RoundedCornerShape(14.dp))
            .background(skin.face)
            .pointerInput(Unit) { detectTapGestures(
                onPress = { pressed = true; tryAwaitRelease(); pressed = false },
                onTap = { onClick() }) }
            // 三层 inset 边线用 drawBehind 画 1px 顶/底线 + 内描边
            .drawBehind { /* edge / top / bottom / press */ },
        contentAlignment = Alignment.CenterStart
    ) { Text("开始今日", color = skin.fg, fontSize = 13.5.sp,
             fontWeight = FontWeight.SemiBold) }
}
```

> Compose 没有 `inset box-shadow`，用 `drawBehind` 画 1px 内缘线即可；`--cta-blur` 对应 `Modifier.blur` 或 `RenderEffect` 作用在其**背后**的内容层，不是按钮自身。

### Android View（XML）

- `--cta-face` → `res/drawable/cta_face_*.xml`（`shape` + `gradient`），7 份
- 内缘线 → `layer-list` 里叠 1px `top` / `bottom` / `stroke` item
- 按下 `scale(.972)` → `StateListAnimator` 或 `ViewPropertyAnimator`
- 皮肤切换 → 重新设置 `background` + `StateListAnimator`，**不要**换 View

## 5. 无障碍与验收清单

| # | 检查项 | 标准 |
|---|---|---|
| 01 | 七档文字对比度 | 全部 ≥ 9:1（高对比档 ≈ 16:1） |
| 02 | 触控目标 | ≥ 48px |
| 03 | 键盘 / 焦点 | 原生 button，Tab 可达，空格 / 回车触发，`:focus-visible` 2px 琥珀描边 |
| 04 | 状态播报 | `role="status"` / `aria-pressed`，不依赖颜色单通道 |
| 05 | 减弱动效 | `prefers-reduced-motion` 下去除缩放与回弹，改用 2px 内描边 + 状态文字 |
| 06 | 系统设置 | 增加对比度 / 降低透明度 → 自动切 `contrast` |
| 07 | 底缘 | 任何档位、任何状态下**不得出现白色亮边**（这是上一版被否的原因） |
| 08 | 切换 | 不重建视图、不丢焦点、不闪白 |
| 09 | 回退 | 未知 id 静默回退 `glass` |
| 10 | 结构 | 七档始终 1 个形状、0 个伪元素、0 层发光 |

## 6. 七档速查

| id | 名称 | 族 | 出处 | 对比度 |
|---|---|---|---|---|
| `glass` | 液态玻璃（默认） | 玻璃 | Apple HIG · clear | ≈ 9:1 |
| `frosted` | 磨砂 | 玻璃 | Apple HIG · regular | ≈ 9:1 |
| `system` | 系统填充 | 实心 | One UI · gray contained | ≈ 9:1 |
| `well` | 内凹 | 实心 | One UI 7 / HyperOS 滑块槽 | ≈ 12:1 |
| `ghost` | 幽灵描边 | 极简 | 用户认可档 | ≈ 13:1 |
| `row` | 列表行 | 极简 | iOS 列表行 | ≈ 13:1 |
| `contrast` | 高对比 | 系统 | HIG · Increase Contrast | ≈ 16:1 |
