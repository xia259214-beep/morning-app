## v1.21.2（23:3x）答题自动上报，真人自动上榜
- 用户反馈：平板+手机都答了题，榜上只看得到一台设备。
- 根因：`LeaderSync.upload()` 只在「上报分数」按钮里调用，从没自动触发 → 云端永远 0 条，榜上「0 位真人」。
- 修：新增 `uploadAuto({force})`（90 秒节流：90s 内合并）；pages_quiz `onAnswered` 里 fire-and-forget 调用；`RankPage.initState` 打开即 `uploadAuto(force:true)` 后再 `_pull()`（不再受 3h 节流限制）。
- 文案：计数改「目前榜上就你 1 位真人」/「N 位真人（含你）」，避免「答了题还显示 0 位真人」。
- 验证：真机打开榜单 → 云端自动出现 `d39b9263…` 行（HTTP 201）；临时插 `probe_phone_0002`（阿满 9 分）→ 榜显示 2 位真人（含你）、自己第 3 名、追超目标正确；测完用 genie-baas SQL 删除（REST DELETE 匿名角色无权限，42501）。
